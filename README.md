# Метод експертних попарних порівнянь з уточненням ступеня переваги

Програмна реалізація методу експертних попарних порівнянь (AHP-подібний підхід) з підтримкою шести типів шкал оцінювання.

## Опис

Цей застосунок реалізує алгоритм експертного оцінювання альтернатив методом парних порівнянь, описаний у документації Opys. Програма дозволяє експертам обирати з шести різних шкал оцінювання, уніфікує всі порівняння до єдиної кардинальної шкали (1.5–9.5), обчислює нормалізовані ваги та перевіряє узгодженість результатів.

## Основні можливості

### 1. Шість типів шкал експертного оцінювання

1. **Ординальна** — проста порівняльна шкала (менше/більше)
2. **Цілочислова** — шкала з 9 градаціями (1–9)
3. **Збалансована** — рівномірний розподіл від 3 до 9 градацій
4. **Степенева** — експоненційна шкала з 3–9 градаціями
5. **Ма-Чженга** — дробова шкала (9/9–9/1)
6. **Донеган-Додд-МакМастера** — модифікована логарифмічна шкала

### 2. Функціональність

- ✅ Введення альтернатив вручну або з файлу
- ✅ Вибір типу шкали для кожного порівняння
- ✅ Інтерактивний інтерфейс порівняння з візуалізацією
- ✅ Уніфікація всіх оцінок до єдиної кардинальної шкали
- ✅ Обчислення ваг методом власного вектора
- ✅ Перевірка узгодженості (λ_max, CI, CR)
- ✅ Рекомендації для покращення узгодженості
- ✅ Експорт результатів у CSV та JSON

### 3. Метрики узгодженості

Програма автоматично обчислює:
- **λ_max** — максимальне власне значення
- **CI** — індекс узгодженості (Consistency Index)
- **CR** — коефіцієнт узгодженості (Consistency Ratio)

Якщо CR > 0.10, система пропонує рекомендації для перегляду найбільш суперечливих порівнянь.

## Використання

### Крок 1: Введення альтернатив

1. У панелі "Введення альтернатив" введіть назви альтернатив (по одній на рядок)
2. Або завантажте з текстового файлу
3. Натисніть "Почати порівняння"

### Крок 2: Парні порівняння

1. Оберіть тип шкали з шести доступних варіантів
2. Виберіть кількість градацій (3, 5, 7 або 9)
3. Для кожної пари альтернатив вкажіть ступінь переваги:
   - Для ординальної шкали: Менше/Більше
   - Для інших шкал: використайте слайдер
4. Натисніть "Підтвердити"
5. Повторіть для всіх пар

### Крок 3: Перегляд результатів

1. Після завершення всіх порівнянь результати відображаються автоматично
2. Таблиця показує ранги, ваги та відсотки для кожної альтернативи
3. Панель метрик показує CI, CR та стан узгодженості
4. Експортуйте результати у CSV або JSON

## Алгоритм

1. **Введення даних**: користувач вводить альтернативи
2. **Парні порівняння**: для кожної пари (i, j):
   - Експерт обирає шкалу
   - Вказує перевагу альтернативи i над j
   - Система зберігає a[i,j] та розраховує a[j,i] = 1/a[i,j]
3. **Уніфікація**: всі оцінки приводяться до кардинальної шкали (1.5–9.5)
4. **Обчислення ваг**: використовується метод власного вектора
5. **Перевірка узгодженості**: розрахунок λ_max, CI, CR
6. **Результати**: відображення рангів, ваг та експорт

## Формули

### Індекс узгодженості (CI)

```
CI = (λ_max - n) / (n - 1)
```

де n — кількість альтернатив, λ_max — максимальне власне значення матриці.

### Коефіцієнт узгодженості (CR)

```
CR = CI / RI
```

де RI — випадковий індекс (залежить від n).

### Критерій узгодженості

Матриця вважається узгодженою, якщо **CR ≤ 0.10** (10%).

## Обмеження

- Мінімум 2 альтернативи
- Максимум 15 альтернатив (обмеження RI)
- Усі порівняння мають бути завершені
